## Installation Notes

### Plugin Installation Best Practices
1. **Always run installers as Administrator**
2. **Install to default VST paths** (C:\Program Files\VSTPlugins or C:\Program Files\Common Files\VST3)
3. **Reboot after installing audio drivers** (FlexASIO, RTL Utility)
4. **Scan plugin directories in DAW** after bulk installation
5. **Keep installers** for version control and troubleshooting

### Known Dependencies
- **Equalizer APO** requires **Peace** for GUI
- **Xfer plugins** may require separate authentication
- **Spectrasonics** plugins require large disk space (50GB+ each)
- **Plugin Alliance** plugins need manager for licensing
- **iZotope** plugins need Product Portal for licensing

### Plugin Manager Configuration
- Configure VST paths in each manager after installation
- Some managers auto-detect plugins, others require manual scanning
- Keep managers updated for best compatibility

### Post-Installation
1. Verify all plugins load in DAW
2. Activate/authorize plugins requiring licenses
3. Backup plugin presets and settings
4. Create DAW template with favorite plugins
