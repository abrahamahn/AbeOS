## 📖 Documentation Conventions

### File Naming
- User documentation: `lowercase-with-hyphens.md`
- Developer documentation: `descriptive-name.md`
- Architecture docs: `UPPERCASE.md`

### Document Structure
1. **Title** - Clear, descriptive heading
2. **Metadata** - Last updated date, version
3. **Overview** - What this document covers
4. **Content** - Well-organized with headers
5. **Related Links** - References to other docs
